# Configurable administration and content authority boundary

- Status: Accepted boundary; data model deferred
- Date: 2026-09-26
- Scope: CORECROW and NORTH

CORECROW will own persisted authorization and tenant isolation for future admin
categories, subcategories, panels, components, and content. NORTH will own the
editor and renderer UI and will consume approved versioned contracts. Visibility
must be authorized server-side; a hidden frontend control is never sufficient.

No category, component, content, draft, revision, or publication schema is
introduced by this decision. Those contracts require the forthcoming product
specification, including content types, validation, ordering, revision and
publication semantics, and resource-level authorization.
