# Public showcase (demo provisioning retired)

> Task Pack 12 removed the provisional SHARK demo seed from the codebase. The showcase *feature* below is generic and remains; the demo organization it was provisioned on must not be re-created by code (see the NORTH repository: docs/task-pack-12/LEGACY_CLEANUP.md).

- Status: Accepted (demonstration scope)
- Date: 2026-10-05
- Scope: CORECROW NORTH public contracts

## Decision

An organization may publish a read-only, anonymous showcase. It is a separate,
explicit and revocable publication policy and never reinterprets the member
audiences (`ALL_MEMBERS`, roles, groups) as public.

A public read requires ALL of: an `ACTIVE` organization with
`Organization.showcaseEnabled`, an `ACTIVE` category and subcategory that are not
hidden, and a `PUBLISHED` `CONTENT` panel with `visibility = SHOWCASE`. Anything
else, including a missing slug, is the same generic `404`, so private structure
cannot be enumerated. Both flags default to private and are set through
authorized, audited mutations (`PATCH .../public-showcase`,
`PUT .../panels/:panelId/public-visibility`, capability `north.panel.publish`).

Contracts (no authentication, no cookie, rate limited):

- `GET /v1/public/showcases/:slug/navigation` — only branches that contain a public panel.
- `GET /v1/public/showcases/:slug/resolve` — the published revision, without author or internal fields.
- `POST /v1/public/showcases/:slug/panels/:panelId/analytics-bindings/:bindingId/results` —
  the same bounded query engine and allowlisted runtime filters as the member path,
  only for a binding referenced by the published public revision.

Navigation and resolve send `Cache-Control: public, max-age=15, must-revalidate`
(revocation propagates within seconds); results are `no-store`.

## Departure from the original showcase task

`TASK_PUBLIC_ORGANIZATION_SHOWCASES.md` excluded anonymous data queries. A data
report such as Master House cannot be shown without them, so this decision
permits them under stricter conditions: the owner must opt in per organization
AND per panel, the response is limited to the binding's declared aggregate query
and allowlisted filters (at most 10, bounded rows), requests are rate limited,
and dataset ACLs remain irrelevant to anonymous callers by design. **Never enable
the showcase on an organization whose datasets contain real or confidential
data.** The SHARK demo uses fully synthetic data generated by
`scripts/build-demo-fixture.mjs`.

## SHARK demo provisioning

`seed-tenant-demo` takes `--public-showcase=true` to enable the organization
showcase and mark the eight Master House pages `SHOWCASE`. The workflow creates
the organization `shark` ("SHARK"). Members are still added with
`--viewer-emails`; the showcase needs no membership.

## Consequences

- `showcase` is a reserved organization slug (NORTH reserves it as a root path).
- Disabling the organization flag, reverting a panel to `PRIVATE`, unpublishing or
  archiving it, or suspending the organization revokes access immediately.
- The migration is additive; existing organizations and panels stay private.
